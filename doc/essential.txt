1. INTRODUCTION                                        *essential-introduction*

essential is a monochrome colorscheme. All code uses a single foreground
color. Structure comes from style (italic comments, bold keywords), not from
hue. Color is reserved for places where it carries meaning:

  - git: add = green, change = blue, delete = red
  - diagnostics: error, warn, info, hint, ok
  - LSP completion and symbol kinds (blink.cmp, dropbar)
  - file icons (mini.icons)
  - search and TODO/FIXME/NOTE markers

Highlights are compiled to LuaJIT bytecode and cached, so a cached load takes
a few milliseconds.

==============================================================================
2. USAGE                                                      *essential-usage*

>lua
    require("essential").setup({})   -- optional
    vim.cmd.colorscheme("essential")
<
                                  *essential* *essential-light* *essential-dark*
  essential         follows 'background' (or the `variant` option)
  essential-light   always light
  essential-dark    always dark

Neovim detects the terminal background at startup. When you use `essential`,
the theme follows the terminal and switches when 'background' changes.

3. CONFIGURATION                                             *essential-config*

Defaults:
>lua
    require("essential").setup({
      variant = "auto",        -- "auto" | "light" | "dark"
      transparent = false,
      terminal_colors = true,
      dim_inactive = false,
      muted_comments = false,
      float = { solid = false },
      styles = {
        comments = { italic = true },
        keywords = { bold = true },
        functions = {}, variables = {}, strings = {},
        types = {}, constants = {}, operators = {},
      },
      integrations = {
        blink = true, dropbar = true, gitsigns = true, grug_far = true,
        lazy = true, mason = true, mini = true,
        semantic_tokens = true, treesitter = true,
      },
      cache = true,
      on_colors = nil,         -- fun(colors, variant)
      on_highlights = nil,     -- fun(hl, colors, variant)
    })
<
                                                          *essential-on_colors*
on_colors(colors, variant)
    Change the palette before highlights are built. Keys: `bg`, `fg`, `red`,
    `orange`, `yellow`, `green`, `cyan`, `azure`, `blue`, `purple`, `accent`,
    `surface1`, `surface2`, `surface3`, `border`, `muted`, `bg_dim`,
    `bg_float`, `git.{add,change,delete}`,
    `diag.{error,warn,info,hint,ok}`.

                                                      *essential-on_highlights*
on_highlights(hl, colors, variant)
    Change or add highlight groups. `hl` maps group names to
    |nvim_set_hl()| specs, with colors as "#rrggbb" strings.

The compiled cache is keyed by a hash of your options, so changes take effect
on the next `:colorscheme`. The hash covers function bodies but not captured
upvalues. If you change such a value, run |:EssentialCompile|.

==============================================================================
4. COMMANDS                                                *essential-commands*

                                                            *:EssentialCompile*
:EssentialCompile       Delete and rebuild the compiled cache, then reload.

                                                         *:EssentialClearCache*
:EssentialClearCache    Delete the compiled cache.

                                                             *:EssentialExtras*
:EssentialExtras [dir]  Write the Ghostty, Kitty and Lazygit themes to [dir]
                        (default: the plugin's `extras/` directory).

==============================================================================
5. API                                                          *essential-api*

require("essential").setup({opts})         Configure.
require("essential").load({name})          Apply a colorscheme by name.
require("essential").colors({variant})     Return the full palette.
require("essential").highlights({variant}) Return the final highlight table.
require("essential").compile()             Same as |:EssentialCompile|.
require("essential").clear_cache()         Same as |:EssentialClearCache|.
require("essential").extras({dir})         Same as |:EssentialExtras|.

==============================================================================
6. EXTRAS                                                    *essential-extras*

extras/ghostty/essential-{light,dark}
    Copy to ~/.config/ghostty/themes/ and set:
    `theme = light:essential-light,dark:essential-dark`

extras/kitty/essential-{light,dark}.conf
    Copy to ~/.config/kitty/{light,dark}-theme.auto.conf.

extras/lazygit/essential-{light,dark}.yml
    Merge into config.yml, or append to LG_CONFIG_FILE.
